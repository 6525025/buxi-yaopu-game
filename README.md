# 不息药铺

一款融合订单规划、资源管理与棋盘压力的策略消除小游戏。

## 在线游玩

[打开《不息药铺》](https://6525025.github.io/buxi-yaopu-game/)

## 核心玩法

- 在回合或晦气耗尽前完成四张灵客药方。
- 点击两枚以上上下左右相连的同类药材进行采集。
- 药方外的材料会转化为灵息，用于引灵、霆火和净坛三种法术。
- 小组消除会增加晦气，大组可以抑制或净化晦气。
- 每完成一张药方，可从时间、净化和灵息奖励中三选一。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

然后访问 `http://localhost:3000/`。

## 构建

```bash
npm run build
npm run build:pages
```

在线版本发布在仓库的 `gh-pages` 分支；更新游戏后可重新生成静态版本并发布该分支。
